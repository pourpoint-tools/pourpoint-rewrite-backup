# Pourpoint

Pourpoint is a Python watershed-delineation engine. It consumes compiled
[HFX datasets](hfx/index.md) to select upstream sub-basins, refine point watersheds
on native D8 grids, select river networks and export portable QGIS projects.

- [Getting started](getting-started.md): installation, datasets and source lifetime.
- [Concepts](concepts.md): contributing area, resolution and scientific assumptions.
- [Operations](operations.md): selection, batches, rivers and portable output.
- [API reference](reference/operations.md): signatures and behavior from source docstrings.
- [HFX specification](hfx/index.md): the current input contract, maintained by HFX.

Documentation is private during development. The intended public address is
https://pourpoint-tools.github.io/; public publication requires maintainer approval.
